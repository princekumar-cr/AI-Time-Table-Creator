Build a professional full-stack web application named "AI Timetable Creator".

Tech Stack:
- Frontend: HTML5, CSS3, TailwindCSS, Vanilla JS (or minimal JS)
- Backend: Golang (Gin or Fiber framework preferred)
- Database: PostgreSQL or MySQL
- AI Integration: OpenAI API for timetable auto-generation
- Architecture: Clean MVC structure

Goal:
Create a smart AI-based timetable management system for colleges, universities, and schools where teachers or timetable coordinators can easily generate optimized timetables using AI.

- Admin login

4. AI Timetable Generator

Include a large text area labeled:
"Describe Constraints / Preferences"

Example:
- Teacher unavailable on Tuesday
- Lab requires 2 consecutive periods
- Max 2 theory classes per day
- Avoid last period for OS

Button:

AI PROMPT STRUCTURE (IMPORTANT)
=====================================================

When calling OpenAI, send prompt like:

"You are an academic timetable optimization engine.
Generate a weekly timetable for the following data:

College: {{college_name}}
Course: {{course}}
Semester: {{semester}}
Section: {{section}}

Subjects:
- Computer Networks (4 hrs/week) – Upasana Rana
- Operating System (4 hrs/week) – Deepak Kumar Pathak
- Programming in Java (5 hrs/week) – Anup Chamoli
- Fundamental of IoT (3 hrs/week) – Divya Pandey
- Linux Lab (2 consecutive hrs) – Deepak Kumar Pathak

Constraints:
- No teacher should have overlapping classes
- Lab must be consecutive
- Max 2 theory classes per day
- Working Days: Monday to Friday
- 6 periods per day

Return only JSON in this format:
{
  "Monday": ["Subject-Teacher", "Subject-Teacher", ...],
  "Tuesday": [...]
}
"
